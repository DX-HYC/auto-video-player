# 自动连播助手（Chrome / Edge 扩展）

一个通用的浏览器扩展：自动识别网页里正在播放的视频和播放列表，视频暂停时自动续播，播放结束后自动点击下一个视频。

## 功能

- **自动识别视频**：扫描页面中所有 `<video>` 元素，并监听动态加载的新视频（含 iframe 内嵌播放器、Shadow DOM）。
- **暂停自动续播**：检测到视频被暂停（非播放结束）时，自动恢复播放。
- **识别待播列表**：用启发式算法解析课程/播放列表，区分 **已播 / 播放中 / 待播** 状态；自动穿透 iframe，识别主页面和子页面中的目录。
- **自动连播**：当前视频播放结束后，优先点击平台自带的"下一集"按钮；没有时按目录顺序点下一个待播项，遇到未展开目录会自动展开父级后再点击。
- **倍速播放**：可选开关，支持 1.0x ~ 5.0x 多档倍速，视频切换后自动保持，关闭即恢复 1 倍速。
- **读取视频进度条**：实时显示当前视频播放进度（`00:33 / 34:06`）和课程总进度百分比。
- **悬浮面板**：页面右下角实时显示运行状态、视频数量、目录统计，可拖拽、可折叠，支持手动"立即播放下一集"，可展开调试日志查看识别过程。

## 安装步骤

1. 打开 Chrome 或 Edge，地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择本文件夹（`auto-video-player`，包含 `manifest.json` 的那一层）。
5. 打开任意视频网站（B站、YouTube、课程网站等），页面右下角会出现悬浮面板即表示已生效。

## 使用

- 面板 / 扩展图标弹窗里可开关：**总开关**、**暂停自动续播**、**播完自动下一集**、**倍速播放**。
- 设置通过 Chrome 同步存储，改动会实时生效到已打开的页面。
- 若不希望某些页面自动运行，可在扩展详情里通过「网站访问权限」限制。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展清单（Manifest V3） |
| `content.js` | 核心逻辑：视频识别、续播、列表识别、连播、悬浮面板 |
| `content.css` | 悬浮面板样式 |
| `popup.html` / `popup.js` | 扩展图标弹窗（设置面板） |
| `icons/` | 扩展图标 |
| `gen_icons.py` | 图标生成脚本（可删除） |

### v1.7.7
- 修复「仍未按顺序播放，且播完最后一个视频后不会回头补齐漏看课时」：
  - `findNextItem` 改为**自动补齐模式**：自动连播时按目录顺序取**第一个未完成课时**，不再局限于「当前项之后」。这样即使前面有漏掉的视频，播完后也会回头继续播放，直到课程全部完成。
  - 手动点击「立即播放下一集」仍优先取当前项之后的下一个未完成课时，保持操作预期；当前项之后没有待播项时，再兜底取全局第一个未完成项。
  - `clickNext` 增加 `autoEnded` 参数，自动结束事件与手动按钮使用不同策略，并在跨帧广播中传递 `manual` 标志。
  - 全部课时完成后日志输出「全部课时已完成」，避免无意义重复跳转。

### v1.7.6
- 修复「v1.7.5 仍未拦住播放器帧乱点 / 当前项识别错位」：
  - `clickNext` 目录有效性判断由「leafCount ≥ 3」改为「本帧必须含 `.s_point[itemtype="video"]`」。网梯内容帧（播放器控件）即便识别出 3 项也不算目录，必须让顶层调度到真正拥有 `.s_learnlist` 的目录帧。
  - `pickBestFrameForNext` 同样过滤掉不含 `.s_point` 的无效帧，委派的目标帧一定是真实目录帧。
  - `analyzeList` 当前项识别顺序改为 **URL 匹配优先**，再退回到 `s_pointerct` 类标记。原因：平台可能在目录上保留对某一项的 `s_pointerct` 高亮，但用户实际播放的是另一项（URL 不同），此时按 `s_pointerct` 找当前项会指错，导致下一集跳过多个真实未看项。
  - 行为：用户从 leaf[N]（未标 `s_pointerct`）播放结束 → 用 URL 识别为 leaf[N] → 下一集严格取 leaf[N+1] 之后的第一个非已完成项。

## 说明与限制

- "识别列表"采用通用启发式策略，大多数主流视频网站都能命中；极少数结构特殊的网站可能需要针对该站做适配。
- 自动续播依赖页面已发生过用户交互（浏览器自动播放策略），正常浏览观看场景下均满足。
- 本工具仅用于个人学习、课程连播等合法场景，请遵守目标网站的条款。
